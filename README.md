# Python Scientific Calculator

A desktop calculator built with Python and Tkinter, featuring standard arithmetic, scientific calculations, and unit conversions in a modern graphical interface.

## Features

- **Standard Calculator:** Addition, subtraction, multiplication, division, percentages, and powers.
- **Scientific Calculator:** Trigonometric functions, inverse trigonometry, logarithms, square roots, factorials, and mathematical constants.
- **Unit Converter:** Length, weight, temperature, time, data storage, area, volume, speed, energy, pressure, power, angle, and fuel economy.
- **Calculation History:** Review, reuse, and clear previous calculations.
- **Keyboard Support:** Perform calculations using your keyboard.
- **Memory Support:** Store and recall calculator values.
- **Graphical Interface:** Built using Python's Tkinter library.

## Technologies Used

- Python
- Tkinter
- Math
- AST-based expression evaluation

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/nobothere123/python-scientific-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-scientific-calculator
   ```

3. Run the application:

   ```bash
   python python_scientific_calculator.py
   ```

No third-party Python packages are required. Tkinter must be available in your Python installation.

## Example Calculations

| Expression | Result |
|---|---:|
| `sqrt(144)` | 12 |
| `sin(30)` | 0.5 |
| `log(100)` | 2 |
| `factorial(5)` | 120 |
| `2^8` | 256 |

Trigonometric functions use degrees by default.
